Module Test_utils.Config_dep_resolution

Which configuration each test-running site's process reads, and whether its dependencies name it: config_dep_completeness's resolution, over a tree handed in as data (gh-ocannl-603).

The resolution half of test/operations/config_dep_completeness (gh-ocannl-603): given the dune files of a tree and where its ocannl_config files are, which configuration each test-running site's process will read, whether the site's dependencies name THAT one, whether a change of the ambient environment reaches the run, and which exemptions were spent.

The scanner half, Dune_stanza_scan, is pinned by test/operations/dune_scan_cases on text built to break it. This half used to live inside the check's let () = main, where its only test was a golden over the live repository -- which can say "today's tree is consistent" and never "a tree where X is wrong gets rejected". Twenty-odd review rounds of resolution fixes (a sibling directory's config, a cross-directory copy_files, exemption-after-availability ordering, the root normalization and the root exclusion) were each validated by planting files by hand and reverting them, and none left a test behind. Here the resolution reads nothing from the filesystem: it takes the tree as data and returns its verdicts as data, so test/operations/config_dep_resolution_cases can hand it synthetic trees with known answers.

What it returns is typed rather than worded: the check's main turns each verdict into its refusal, keeping every diagnostic a literal in the scanner source, where the refusal-control catalogue (Refusal_control_manifest) finds and holds it.

val under : Base.String.t -> Base.String.t -> Base.String.t

path, written relative to the repository-relative directory dir, made repository-relative. dir is split into its components first: handed over whole, as one component, a .. in path would pop all of test/a rather than a alone, so a (chdir ../b ...) in test/a would run in a top-level b. That held wherever the dune file sits one level deep, which is where the sibling chdir fixes were validated by hand, and no deeper (gh-ocannl-603).

val search_path : Base.String.t -> Base.String.t list

The directories a process running in directory searches for its configuration, nearest first: directory and every ancestor BELOW the repository root, as Utils.config_file_args walks them.

The root itself is not one of those stops, even though the executable's own search does end there. A root ocannl_config is gitignored personal dev settings, so letting one satisfy a site would make the check pass on the developer's machine and fail in CI, for the very directory whose missing (copy_files ../config/ocannl_config) it exists to catch (lukstafi/ocannl-staging#346). Only a config a checked-in stanza puts in reach counts.

val nearest_config : has_config:(Base.String.t -> bool) -> Base.String.t -> Base.String.t option

The first directory on directory's search_path that has_config: both the file that must exist and the one the dependency must name, whether the process runs in a descendant of the stanza's directory, a sibling, or the stanza's own (Codex P2, rounds 9 to 11 of PR #343).

val declares_nearest : stanza_dir:Base.String.t -> nearest:Base.String.t -> Base.String.t Base.List.t -> bool

Whether one of declared -- dependency paths as the stanza in stanza_dir writes them -- names the config in nearest: the one the process will actually read, not merely some ancestor's (Codex P2, round 10 of PR #343). Paths are resolved from the stanza's directory before comparing.

type verdict =
  1. | Counted
    (*

    declares the config its process reads, and the ambient environment reaches it

    *)
  2. | Exempt
    (*

    an exemption was spent on it

    *)
  3. | No_config_in_reach
    (*

    no directory on its search path has a config to depend on

    *)
  4. | Unestablished_directory
    (*

    a shell action, not exempt: which config the process finds cannot be established

    *)
  5. | Ambient_unreached of Base.string
    (*

    declares the config in this directory ("." for the root), which carries no record of the ambient environment, and depends on neither that record nor (universe)

    *)
  6. | Unreadable_undeclared
    (*

    runs a command the scan cannot read, and declares no config

    *)
  7. | Unclassified_undeclared
    (*

    has an action head the scan cannot place, and declares no config

    *)
  8. | Undeclared
    (*

    declares no config, or not the one its process reads

    *)

The ambient producer (gh-ocannl-1149): test/config/dune records the ambient OCANNL_* environment in ocannl_ambient, under (universe), and appends that record to the shared configuration as test/config/ambient/ocannl_config. The whole guarantee rests on both rules, so they are checked rather than trusted -- and, since gh-ocannl-1038, the host record too.
