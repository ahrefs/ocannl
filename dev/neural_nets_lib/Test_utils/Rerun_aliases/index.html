Module Test_utils.Rerun_aliases

Which aliases re-run a file that pins the text of generated code: read from the dune files, the rule diffing a golden or the stanza running a source (gh-ocannl-1533).

Which aliases re-run a file that pins the text of generated code (gh-ocannl-1533).

codegen_text_inventory says WHAT a codegen change must re-run; this says HOW, as the per-test aliases dune build (or tools/test-run.sh run build) takes. Knowing the file is not knowing the alias: the test stanza runtest-top_down_prec runs that test and diffs nothing but its own .expected, while the kernel snapshots top_down_prec.<ext>.expected are compared only by the hand-written runtest-top_down_prec-extension rule beside it -- and which of the four snapshots that rule compares depends on the backend the build resolves. A codegen author who runs the test by its own name sees green and leaves every snapshot unchecked (staging#1326).

So the aliases are read from the dune files rather than written down beside the inventory, by the same reader the other dune scans share (Dune_stanza_scan):

  • A golden is re-run by the rule whose (diff …) (or (diff? …)) names it as the expected side, matched with each %{…} standing for the text the build substitutes there, and the substitution is reported -- %{read:../config/ocannl_backend_extension.txt} is cu for the CUDA snapshot -- with the backends whose build makes it so, as the configuration reader writing that file decides it (Config_reads, gh-ocannl-1581): cu is CUDA because the reader writes cu for CUDA. A (test)/(tests) stanza re-runs the <name>.expected beside it, under dune's own runtest-<name>.
  • A source is re-run by whatever runs the stanza owning its module: a (test) stanza under runtest-<name>, an (executable) under the alias of each rule that runs it -- or, for a rule that only writes targets, the alias of each rule that reads one -- and an inline-test library under its per-module runner rule (gh-ocannl-1037), or dune's runtest-<library> where it has none. A (select) arm is the module its target names.

The reading stops at the dune files it is handed and at the shapes above. What it cannot place it answers with nothing, and the caller refuses an empty answer: a member nobody can re-run by name is a gap in the census, never a quiet omission from it.
