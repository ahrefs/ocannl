Module Test_utils.Verdict_callee

Whose a claim name is -- Verdict's, ambiguously so past an open of another module, or not: the one resolver every Verdict reader asks (gh-ocannl-1361).

Whose an identifier is: Verdict's, or not -- the one resolver every Verdict reader asks (gh-ocannl-1361).

verdict_ratchet runs several readers over the tree: the quantified-claim provenance layer (Verdict_provenance), the line-break and dialect readers built on Verdict_scan.claim_calls, and the gate reader (Verdict_scan.gate_census). Each used to decide for itself whether a callee was Verdict's, and they disagreed at the edges: the provenance layer read a module Verdict = Local_printer as Verdict and an unqualified p past an open of another module as certainly Verdict's, the gate reader took any unbound gated_all for Verdict's, and staging#1150 spent six review rounds fixing the line-break reader one edge at a time. So the question is answered once, here, by one walk of the source, and the readers look the answer up by the identifier's location.

What it decides

For every value identifier whose last component is a members name (a member of Verdict.Claims), one ownership, resolved through Lexical_scope at the point the identifier is spelled:

  • A QUALIFIED identifier (Verdict.p, V.p, Verdict.Claims.p, C.p) is Verdict's when its module path denotes Verdict: the head Verdict with no binding of that name in scope, a module the source binds to such a path (module V = Verdict, module V = Verdict.Claims), or any submodule of either. A structure of this source (module C = struct ... end) exports a claim name as Verdict's when it includes such a module and binds no value of that name after the include. Any other path is not Verdict's: Other.Verdict.p, a Verdict the source took over (module Verdict = Local_printer), a functor parameter, a module nested in a structure (M.N.p).
  • An UNQUALIFIED identifier resolves through the scope's frames, innermost first. A binding of the source (a let, a parameter, a pattern, an external, a class's names, an open of a structure of the source that binds the name) makes it not Verdict's; an open or include of a module denoting Verdict makes it Verdict's; an open of a module this resolver cannot read is passed over, and makes the name Ambiguous if an open of Verdict is reached past it. A name nothing binds and no open of Verdict brings in is Free.

Ambiguity

What a module this resolver cannot read exports is unknowable: it may define a value named p, or a submodule named Verdict. Staging#1150 met both failure directions of that one fact -- read as "not Verdict's", every claim after an open Ll_test went silently unchecked; read as "certainly Verdict's", a module exporting its own p would be refused with no way out but renaming. So a name that reaches Verdict only past such an open is Ambiguous: every reader still reads it, and a refusal of one adds the remedy, to qualify the call if it is the other module's. That covers qualified paths too: past an open of an unreadable module, Verdict.p (and an alias of Verdict) may name that module's own Verdict.

The modules this resolver can read are Verdict itself, the structures of the source, and the standard libraries (standard_libraries: Base, Core, Stdlib, Caml, Stdio), which export neither a claim name nor a module named Verdict. Any other module -- Ocannl, Ir, Test_utils, a fixture's Other -- is unreadable.

What is not decided here

Which of the ownerships a reader reads: the line-break and provenance readers read Verdicts and Ambiguous; the gate reader reads Free too, since a gated_* name exists nowhere but in Verdict.Claims. And everything beyond the callee's identity -- labels, populations, values bound to a wrapper -- stays each reader's own.
