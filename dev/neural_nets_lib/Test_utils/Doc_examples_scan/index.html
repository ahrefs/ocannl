Module Test_utils.Doc_examples_scan

Bounded executable Markdown: only explicitly selected OCaml is compiled. The reader accepts top-level backtick/tilde fences (up to three leading spaces), the same fences inside one level of block quote (> ```ocaml, as slide containers write them), and one-line Doc-check code spans in agent notes. Unsupported annotated syntax fails loudly. Unselected OCaml fences are inventoried, never guessed into self-contained programs.

A fence of any language may also declare where its code comes from (gh-ocannl-1265), right after the language word: doc-excerpt=<path> says it is a verbatim excerpt of that repository file, which check_provenance holds it to (up to whitespace); doc-adapted=<path> says it is adapted from that file and is held only to the file existing. A fence whose caption -- the line directly above its opening, with no blank line between -- says from <file>.ml must declare one or the other, so library code presented as an excerpt cannot drift unchecked.
