Module Test_utils.Doc_examples_scan

Bounded executable Markdown: only explicitly selected OCaml is compiled. The reader accepts top-level backtick/tilde fences (up to three leading spaces), and one-line Doc-check code spans in agent notes. Unsupported annotated syntax fails loudly. Unselected OCaml fences are inventoried, never guessed into self-contained programs.
