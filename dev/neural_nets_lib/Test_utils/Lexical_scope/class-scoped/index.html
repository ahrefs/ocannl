Class Lexical_scope.scoped

Walks a structure under env. A scan instantiates it with what a name denotes (local, a binding group's define, a module path's module_path) and observes the walk through ident, called on every value identifier with the scope it is spelled in.

What a module path denotes in scope, None for what the scan does not model.

method shadowed : 'm Base.option

What a module name denotes once a binding the scan cannot see into -- a functor parameter, an unpack, a recursive module, a struct -- takes it over. None forgets the name, which is right where an unmodelled name means "not ours"; a scan to which an unbound name means the library module of that name answers a denotation of its own here instead.
