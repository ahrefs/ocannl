Module Winner_fixture

Test-only digest-free replay fixtures extracted from saved autotune winners (gh-ocannl-2394).

Saved autotune cache entries carry regime- and lowering-specific digests (source_digest, per-segment seg_digest, cache keys, versions, and timing diagnostics). When lowering or rendering moves those digests, replaying the saved winner through Schedule_cache fails even though the transforms themselves still apply.

This module strips all cache metadata and digests to keep only the transforms — whole-routine or split-reduce prelude ops and, for fissioned winners, each segment's kind, unit count, and saved ops with canonical axis and tensor-node references — and validates every anchor against a fresh lowering before replaying, refusing by name whenever an anchor no longer exists.

  • Validation guarantee and boundary
  • Accepted input boundary (fail-closed)

Validation guarantee and boundary

Ir.Schedule_cache.entry persists only canonical preorder ordinals (Base i, Static k, tensor-node index n) and never loop extents or tensor labels, so an extracted fixture carries no external names for them. validate therefore gives a positional-plus-structural guarantee: segmentation coverage, `Zeros segment kind coherence, unambiguous resolution of every referenced axis and tensor-node ordinal, and live op preconditions on a hermetic copy. It cannot detect a lowering change that swaps two structurally compatible loops or tensor nodes while leaving every op legal; regression tests pinning a winner should pair replay with structural and/or value assertions (placement, MMA census, output parity).

Accepted input boundary (fail-closed)

extract_file reads only Ir.Schedule_cache's on-disk stored-entry format ((key <k>) (payload <entry>)) via Ir.Schedule_cache.read_entry_file and Ir.Schedule_cache.entry_of_sexp. Entries in the "placements-" or "abandonment-" key namespaces, unreadable or unparseable files, non-entry payloads, empty segmentations (segments ()), and segments with non-positive unit counts are refused with a named error. Older entry_version values whose payload schema decodes with Ir.Schedule_cache.entry_of_sexp are accepted without checking entry_version or cache_regime_version.

val validate : is_gpu:Base.bool -> limits:Ir.Backend_intf.hardware_limits -> ?static_indices:Ir.Indexing.static_symbol Base.list -> t -> Ir.Low_level.optimized -> (Base.unit, anchor_error) Base.Result.t

Validates fixture against a hermetic copy of opt without mutating opt:

  • checks fixture structure and segmentation coverage against opt's lowered units (including `Zeros segment kind coherence and scope-local containment),
  • checks every axis anchor (Base, Static, Minted including op-index ordering and role validity against the fresh lowering's node ranks) and tensor-node anchor (tn, source, target) in prelude and every segment before applying transforms,
  • applies the validated transforms hermetically so stale structural preconditions (a loop consumed by an earlier op, a missing Zero_out, non-nested Swap loops, a missing epilogue) are refused by name before any real compile runs.
val replay : is_gpu:Base.bool -> limits:Ir.Backend_intf.hardware_limits -> ?static_indices:Ir.Indexing.static_symbol Base.list -> t -> Ir.Low_level.optimized -> (Ir.Low_level.optimized Base.list, anchor_error) Base.Result.t

Runs validate on a hermetic copy of opt first, then replays fixture onto opt through the production prelude / Autotune.tuner_fission pipeline, returning the scheduled kernel list. Leaves opt untouched when validation fails.
