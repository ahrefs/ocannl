Module Tune_crown

val finals_word : Autotune.finals_outcome -> Base.String.t

Autotune.finals_outcome_name as one field word: "not run" reads as not_run.

val finals_fields : Autotune.report -> string

The finals' outcome and how many contenders they re-timed (zero when they did not run).

val fields : Autotune.report -> string

The call's outcome, the crowned candidate's label and search reading, then finals_fields. The label is "" exactly when nothing was timed, which outcome then explains.

val eprint : site:string -> Autotune.report -> Base.unit

A ~report callback for a test: prints <site>: tune <fields> (not part of the golden) on stderr.
