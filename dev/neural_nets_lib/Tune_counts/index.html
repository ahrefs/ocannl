Module Tune_counts

type count = [
  1. | `Reached
  2. | `Admitted
]
val departures : count -> Autotune.report -> string Base.List.t
val skipped_on : string
val claim : count:count -> tag:string -> Autotune.report Base.List.t -> Base.String.t -> Base.bool -> Base.unit

claim ~count ~tag reports label ok is Verdict.p label ok when none of reports records a departure that moves a count claim, and an `Environment skip of label otherwise, with each report's departures on stderr under tag (not part of the golden). A claim comparing two searches passes both reports.
