Module Lineage_claims

The claim helpers of the lineage-refusal tests (gh-ocannl-1724, gh-ocannl-1744, gh-ocannl-1781): a refusal's text, an accepted call, an exact readback, a tensor's gradient node and a substring test. Six tests carried their own copies, one of them without the stderr echo of the refusal.

Call them qualified, through an alias (module LC = Lineage_claims, then LC.refusal ...), never under an open: past an open of a module Verdict_callee cannot read, a test's unqualified p reaches Verdict only ambiguously.

val grad_of : Ocannl.Tensor.t -> Ocannl.Tensor.tn

The gradient node of a differentiable tensor; raises on a tensor without one.

val has : Base.String.t -> Base.String.t -> bool

Whether msg contains substring.

val exact : Base.String.t -> Base__Float.t Base.Array.t -> Base__Float.t Base.Array.t -> Base.unit

A readback equal to want cell for cell.

val refusal : Base.String.t -> (unit -> 'a) -> Base.string

The text of the User_error f raises, echoed to stderr outside the golden; a failed claim when it raises none.

val accepted : Base.String.t -> (unit -> 'a) -> 'a option

Some of what f returns, with a passing claim; a failed claim naming the refusal, and None, when it raises a User_error.
