Module Scheme.For_ppx

The runtime the %op expansion calls. Not for direct use.

val closure : name:Base.string -> arity:Base.int -> (tensor Base.list -> Base.unit) -> handle

Traces now, the body applied to tracers: the () stage of a %op function.

val deferred : name:Base.string -> arity:Base.int -> (tensor Base.list -> Base.unit) -> handle

Traces at the first application: a %op function without a () stage.

val apply : handle -> tensor Base.list -> (Base.unit -> 'a) -> 'a

apply h args body (tracing h's scheme first when pending or stale) runs body guided by the scheme, or checks the scheme against args and then runs body, per the op_shape_schemes setting. Inside a trace, inside a guided application, and when unschemed, only runs body.
