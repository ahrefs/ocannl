Module Scheme.For_ppx

The runtime the %op expansion calls. Not for direct use.

val closure : name:Base.string -> arity:Base.int -> (tensor Base.list -> Base.unit) -> handle

Traces now, the body applied to tracers: the () stage of a %op function.

val deferred : name:Base.string -> arity:Base.int -> (tensor Base.list -> Base.unit) -> handle

Traces at the first application: a %op function without a () stage.

val apply : handle -> tensor Base.list -> (Base.unit -> 'a) -> 'a

apply h args body (tracing h's scheme first when pending or stale) checks the scheme against args, then runs body. Inside a trace, and when unschemed, only runs body.

val closure_variants : name:Base.string -> optional:Base.string Base.option Base.list -> (tensor Base.option Base.list -> Base.unit) -> handle

closure for a function with option-valued tensor parameters: optional names each position's option-valued parameter (None: a required tensor, passed as Some). Traces every presence pattern now.

val deferred_variants : name:Base.string -> optional:Base.string Base.option Base.list -> (tensor Base.option Base.list -> Base.unit) -> handle

deferred likewise: every presence pattern is traced at the first application.

val apply_variants : handle -> tensor Base.option Base.list -> (Base.unit -> 'a) -> 'a

apply for the variant handles: the arguments' presence selects the scheme checked against the present arguments.
