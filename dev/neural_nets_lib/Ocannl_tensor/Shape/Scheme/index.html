Shape schemes (gh-ocannl-404)

The shape-inference half of Tensor.Scheme: use that. A scheme is the constraints a traced function registers, read off the session before the trace's rewind, with the solution equations of their variables; an instantiation renames the variables the trace minted (the generalized ones), keeps the older ones (shared parameters' and every other pre-existing tensor's: fixed), and relates the scheme's boundary rows to given argument and result shapes. It runs no function body and registers no update step: the next closure applies the solution to the boundary shapes and closes them, and finalizes the scheme's internal rows (renamed) as it finalizes an update step's rows.

type shape := t

type sabotage =
  1. | No_generalization
    (*

    Rename nothing: applications share the trace's variables.

    *)
  2. | Sever_shared
    (*

    Rename every variable and drop the anchors: no application stays tied to pre-existing shapes.

    *)
  3. | No_marks
    (*

    Re-add none of the trace's policy marks (instantiate only).

    *)
  4. | No_internal_rows
    (*

    Register none of the scheme's internal rows with the closure (instantiate only).

    *)
  5. | No_end_validation
    (*

    Skip the end-of-trace solve of the whole window (trace only).

    *)
  6. | No_unify
    (*

    Do not unify a guided application's shapes with the scheme's rows (guided only).

    *)
  7. | No_creation_check
    (*

    Match a step whatever its lhs's creation rows (guided only).

    *)

Negative controls for the tests: each disables one part of the mechanism.

val trace : ?sabotage:sabotage -> var_mark:Base.int -> label:Base.string -> args:shape Base.list -> (Base.unit -> shape Base.list) -> t

trace ~var_mark ~label ~args f runs f, which returns the result shapes, and reads the scheme off the session. args are the tracers' shapes, made after var_mark was read with Row.var_mark (so their variables are generalized) and before this call (so their own constraints are not the scheme's). Must run inside a rewound window (Tensor.with_rewind), which undoes the trace. While f runs, finish_inference raises. Refuses, with Untraceable_scheme on what a scheme cannot carry: a precision-dependent total-elements constraint, a capture reference made outside the window and bound or set in it, or forcing dims or projections; and Row.Shape_error on a contradiction among the window's constraints (solved at Stage1 once more at the end, so a trailing set_dim is checked too). Both are prefixed "tracing the shape scheme <label>: ".

val instantiate : ?sabotage:sabotage -> t -> application:Base.string -> args:shape Base.list -> results:shape Base.list -> Base.unit

Adds the scheme's renamed constraints and the equalities of its boundary rows with args and results (and of its anchored pre-existing shapes with their current rows), solves them at Stage1, and registers the boundary shapes and the internal rows with the next closure. Every added constraint carries an origin naming the scheme and application, so a closure-time failure names them too. Raises Row.Shape_error prefixed "applying the shape scheme <label> to <application>: ": before anything is written, on an arity mismatch, a boundary or anchored shape discarded by a rewind, or a closure since the trace when the scheme depends on open state no anchored shape holds; after registering (tainting the session, as a failed construction does), on a contradiction.

val check : ?sabotage:sabotage -> t -> application:Base.string -> args:shape Base.list -> Base.unit

instantiate against args with no results, then puts back everything it wrote (the session and solver globals, the taint, the rows of the arguments and anchored shapes): an argument-dependent shape error raises as instantiate's does, and the session is unchanged either way. Costs what instantiate does, independent of the open frontier.

val has_instances : t -> Base.bool

Whether the traced function applied a scheme explicitly (instantiate): such a scheme's inherited internal rows belong to no step, so it is not applied guided.

val guided : ?sabotage:sabotage -> t -> application:Base.string -> args:shape Base.list -> id_mark:Base.int -> (Base.unit -> 'a) -> 'a

guided s ~application ~args ~id_mark body (gh-ocannl-1761) instantiates s persistently against args (registering no instance) and runs body, whose shapes are those of tensors with ids at least id_mark. Each update step body registers that matches the next step of the trace -- an equal logic key, shapes corresponding to the trace's (the same arguments, the same pre-existing shapes, its own shapes one-to-one), and a fresh lhs created with the trace's rows up to renaming -- registers without get_inequalities: its shapes the trace created are unified with the scheme's renamed rows, and the step is still registered for closure and projections. A matched step with capture references, a uint4x32 conversion, a batch slice or a payload-dependent terminal registers normally, unified too; a step the trace lacked registers normally. A refused instantiation raises as check's does and puts the session back; after it, an exception from body taints the session, and a trace step body did not build raises Row.Shape_error ("the function built a different graph than at its trace"), tainting it.

val stale : t -> Base.bool

Whether instantiate would refuse the scheme for a closure since its trace (the scheme depends on open state no anchored shape holds): trace it again.
