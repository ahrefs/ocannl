Module Test_scan.Codegen_stage_modules

The modules that run after lowering, shared by digest_completeness and cache_key_agreement (gh-ocannl-2440).

Modules that run AFTER lowering: rendering a kernel, compiling it, dispatching it, and building the cache identity itself.

A key whose only reads live here is invisible to the canonical digest by construction. schedule_cache.ml belongs here for the same reason as the backends (Codex P2 on PR #337): it reads its keys while assembling the codegen component, downstream of the code the digest names, so a Code_borne classification of one of them would be wrong in the exact way digest_completeness's check 3 exists to catch.

Shared by digest_completeness (no key read here may be classified Code_borne) and cache_key_agreement (every key read here whose class promises an unchanged kernel must have oracle values in emitted_flips or a documented exemption in emitted_exemptions / codegen_not_traced, even when that backend is not running; gh-ocannl-2440).
