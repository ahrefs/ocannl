Module Test_scan.Markdown_link_scan

Checking the closed inline-link dialect against repository source paths.

Closed dialect: single-line inline links with unnested labels and literal relative file or directory destinations, including angle destinations and optional titles, read by Agent_notes_scan.links_of unchanged. Reference links, images, HTML links, code spans, fences and HTML comments are outside it. Schemed and protocol-relative URLs are ignored. Single-slash root-relative destinations and relative paths containing escapes, percent encoding, queries, entities, colons or parentheses are refused. Fragments are ignored; general-document anchors are not checked.
