Module Test_scan.Sweep_owner_scan

Holding every `Outside_sweep skip to an owner that still resolves: a CI step building the test's alias, or the plain run of the forced executable (gh-ocannl-926).

The reader behind test/operations/sweep_owner_scan (gh-ocannl-926): every `Outside_sweep skip names the matrix that owns its execution (Verdict.sweep_owner), and that matrix still exists.

An `Outside_sweep skip leaves both sweep intersections, so a claim recorded that way is covered only by whatever runs it elsewhere. Before the owner was an argument, that relationship lived in comments: deleting the compiler-trace CI step would have left cc_backend_trace_name's level-3 claim excluded from the backend and the environment dimension alike, with nothing turning red.

  • What it reads
  • What it deliberately does not read

What it reads

  • The corpus: every .ml file of the source tree whose text spells Outside_sweep, parsed with ppxlib. A use is an EXPRESSION `Outside_sweep <arg> (a pattern or a type is not a use). Its argument must be a literal owner: a constructor whose last path component is Ci_step or Plain_run (the type checker has already made it Verdict.sweep_owner's) applied to a record of string constants, every field of the constructor present. Anything else -- a variable, a function call, a computed string, the tag with no argument -- is refused. A file in exemptions spells fixture owners, not the tree's: its uses are neither required to be literal nor resolved, and an exemption whose file has no use is refused as stale.
  • An owner's alias must lie in the use's own directory (only a stanza there can compile the source) and be defined by exactly one stanza of that directory's dune file: a (test)/(tests) stanza through its per-test alias runtest-<name>, or a (rule) through its (alias …)/(aliases …). That stanza must RUN the use's source.
  • Running the source means a command in command position (Dune_stanza_scan.commands_in): a test stanza compiling it (its (modules …) list the file's module, or a (select …) names the file as an arm) runs itself, through its default action or its own (run %{test} …); any stanza's (run %{dep:X.exe} …) or (run %{exe:X.exe} …) runs X when X is an executable or test stanza of the file compiling it. A module a rule of the file copies the source into ((copy# F X.ml), (copy F X.ml)) is the same source. A stanza that only names an executable -- copies it, depends on it -- runs nothing.
  • A Ci_step owner: .github/workflows/<workflow> holds exactly one list item whose name: (on the item's dash line or at the item's own key indentation, quotes stripped) is the step, and one of that item's lines, a trailing YAML or shell comment cut off, spells dune build and after it @<alias> followed by a character that cannot continue an alias; and the item's own env: block sets one of the (env_var …) dependencies the owning stanza declares -- the gate that makes the step's run differ from the sweep's. A stanza declaring none is refused: nothing the scan reads would tell the two runs apart.
  • A Plain_run owner: none of the owning stanza's runs of the source passes the atom forcing, and some stanza of the same dune file runs the source with it -- the forced run whose skips the owner answers for.

What it deliberately does not read

  • Whether a workflow step runs at all: its if:, its job's matrix and triggers are not evaluated, and a dune build @<alias> inside an echo or a quoted string reads as a build. The gate's VALUE is not read (that it opens the gate is the test's), nor a job- or workflow-level env:, nor a variable set inside the run: script: a gate set those ways is refused, the loud direction. A build spelled any other way -- through tools/test-run.sh, or with the alias on a continuation line -- is refused, the loud direction.
  • Whether the owning run evaluates the same CLAIMS: the claim identity differs between the two runs anyway (a forced copy has its own executable name), and labels are the test's to keep equal. The scan pins that the owner exists and compiles the same source, not what it prints.
  • Owners spelled outside the source tree's .ml files, and `Outside_sweep reached through a ppx or a functor: none exists, and the tag must be spelled for the type to be inhabited.
