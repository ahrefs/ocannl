Module Training_golden

Host-side statistics used by training-golden claims.

val recent_mean_exn : count:int -> Base.Float.t Base.List.t -> Base__Float.t

recent_mean_exn ~count values averages the first count values in a newest-first list. It rejects an undersized window so a shortened training loop cannot silently weaken a claim.
