Demo models

Complete example architectures assembled from Nn_blocks: the models the tutorials, tests and benchmarks train end to end. They are demonstrations of composing the blocks rather than reusable components -- copy one and adapt it.

Attention and transformers

val multi_head_att_workshop : num_heads:Base.int -> d_k:Base.int -> d_v:Base.int -> unit -> Ocannl_tensor.Tensor.t -> Ocannl_tensor.Tensor.t

Multi-head self-attention reduced to its core -- no label, mask, dropout or position embedding -- for illustration; Nn_blocks.multi_head_attention is the reusable block.

val transformer : label:Base.string Base.list -> num_encoder_layers:int -> num_decoder_layers:int -> num_heads:Base__Int.t -> d_enc:Base.int -> d_dec:Base.int -> d_ff:Base.int -> ?epsilon:??? -> ?mask_fill:??? -> ?pos_embed:??? -> unit -> train_step:Ir.Indexing.static_symbol option -> src:Ocannl_tensor.Tensor.t -> tgt:Ocannl_tensor.Tensor.t -> mask:Ocannl_tensor.Tensor.t -> Ocannl_tensor.Tensor.t

An encoder-decoder transformer: token embeddings, position encoding per pos_embed, the Nn_blocks.transformer_encoder and Nn_blocks.transformer_decoder stacks, and an output projection.

val transformer_with_loss : label:'a -> model: (train_step:'b -> src:'c -> tgt:'d -> mask:'e -> Ocannl_tensor.Tensor.t) -> unit -> train_step:'b -> src:'c -> tgt_input:'d -> tgt_target:Ocannl_tensor.Tensor.t -> mask:'e -> Ocannl_tensor.Tensor.t * Ocannl_tensor.Tensor.t

Transformer with teacher forcing for autoregressive training.

Convolutional networks

val lenet : ?label:??? -> ?out_channels1:??? -> ?out_channels2:??? -> ?use_padding:??? -> unit -> train_step:'a -> Ocannl_tensor.Tensor.t -> Ocannl_tensor.Tensor.t

LeNet-style architecture for simple image classification (e.g., MNIST). Classic architecture: conv -> pool -> conv -> pool -> fc layers. Output shape is inferred from training data.

val sokoban_cnn : label:Base.string Base.list -> ?num_actions:??? -> unit -> train_step:'a option -> grid_state:Ocannl_tensor.Tensor.t -> Ocannl_tensor.Tensor.t * Ocannl_tensor.Tensor.t

Simple CNN for Sokoban-like grid environments. Processes grid states with multiple conv layers and outputs action logits.

val mobile_cnn : label:Base.string Base.list -> ?num_classes:??? -> ?_width_mult:??? -> unit -> train_step:'a option -> Ocannl_tensor.Tensor.t -> Ocannl_tensor.Tensor.t

Modern CNN with depthwise separable convolutions for efficiency. Suitable for mobile/edge deployment. _width_mult is caller-visible as unimplemented: changing it currently has no effect on channel counts.
