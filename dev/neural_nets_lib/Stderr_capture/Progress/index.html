Module Stderr_capture.Progress

The tuner's progress lines, as arrayjit/lib/autotune.mli documents them (gh-ocannl-1061):

autotune-progress: wall_s=<s> event=<event> <key>=<value> ...

A value is a bare word, or an OCaml-quoted (%S) string, which may hold spaces -- an arm label does.

val prefix : string
type line = {
  1. event : Base.string;
  2. wall_s : Base.float;
  3. fields : (Base.string * Base.string) Base.list;
    (*

    Every key=value of the line, wall_s and event included, in order; a quoted value unquoted and unescaped.

    *)
}
val parse_fields : Base.String.t -> (Base.String.t * Base.String.t) Base.List.t option
val parse : Base.String.t -> line Base.Option.t

parse line is the progress line line read, or None when it is not one or breaks the documented shape: wall_s (a number) and event must lead, in that order.

val is_progress : Base.String.t -> bool

Whether line starts as a progress line, whatever follows.

val of_lines : Base.String.t Base.List.t -> line Base.List.t

The progress lines among lines that parse, in order.

val events : Base.String.t Base.List.t -> Base.String.t -> line Base.List.t

events lines name are the progress lines among lines of event name.
