Module Ir.Cuda_like_config

val cuda_fast_math : unit -> bool

CUDA's math policy (gh-ocannl-1710): whether nvrtc compiles with --use_fast_math (Compiler_options.nvrtc_math_options) and f32 Tanh_approx renders the __tanhf intrinsic. On by default; profile=reproducible turns it off. The one reader of the key, so the compile, the rendering and the CUDA schedule-cache regime cannot disagree.
