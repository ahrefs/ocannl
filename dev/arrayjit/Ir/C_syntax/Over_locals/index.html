Module C_syntax.Over_locals

The two Blend_over_locals renderings, shared by C_syntax.pp_scalar_op and operand_conditionality_violations so the checked text is the emitted one: an immediately-invoked lambda capturing by reference ([&]() { ... }()) that binds the arms to decl locals, in order, then returns the dialect's own short-circuiting spelling over the names. A Where binds both arms, a gate (Relu_gate, Satur01_gate) its gated operand -- its other arm is the spelling's own constant. The first binding's declaration shares the opening line, as cc's blend does, so a reader of the emitted text finds a blend's block by its opening line.
