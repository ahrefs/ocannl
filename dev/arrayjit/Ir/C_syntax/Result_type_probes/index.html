Module C_syntax.Result_type_probes

Result-type probes (gh-ocannl-2117): a test seam asserting, at compile time, the type of each scalar a kernel renders at a float precision. Scope collapse assumes that where Low_level.typed_at holds, the rendered text already has the type a local of its precision is declared with (typ_of_prec); under with_probes every such node of every kernel, leaves included, fails the backend's compile unless it does. Not probed: the explicit-SIMD lanes, integer compute precisions (whose scopes never collapse), and MMA fragments.

type claim = prec:Ops.prec -> Low_level.scalar_t -> Base.bool

Which nodes a probe asserts on: those rendered at prec it holds for.

val marker : Base.string

A string every probe's failure message carries, so a test can tell a result-type failure from another compile failure.

val with_probes : ?claim:claim -> (Base.unit -> 'a) -> 'a

with_probes ?claim f runs f with every kernel rendered in it probed wherever claim (default Low_level.typed_at) holds. A test seam: kernels are never probed outside it. A test passes another claim to show that a probe fails on a type it does not hold.

val active : Base.unit -> claim Base.option
val emitted : Base.unit -> Base.int

How many probes the kernels rendered in this process carried.
