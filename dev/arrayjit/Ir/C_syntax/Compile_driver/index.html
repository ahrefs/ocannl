Module C_syntax.Compile_driver

One driver owns naming, binding order, emission order and batch source assembly. The compiler callback retains ownership of its artifacts and libraries; its return value is shared by every batch member, and its exceptions cross this boundary unchanged -- except one whose compiler report points at a routine's declaration, which is re-raised as the routine NAME's failure (attribute_routine_name_failure, gh-ocannl-707).

type 'kparams rendered = {
  1. entries : ('kparams * Base.string * Low_level.launch_dims) Base.array;
    (*

    Per kernel, in batch order: its parameters, its emitted name and its launch geometry.

    *)
  2. assemble : Base.int Base.list -> Base.string;
    (*

    The source of one translation unit holding the kernels at these indices, in the given order: the includes, the builtins those kernels use and their definitions, conditional includes applied. assemble of every index in order is the batch source compile_batch hands its compiler; assemble [i] is kernel i's standalone source, which a kernel code cache keys on (gh-ocannl-1314).

    *)
  3. assemble_units : Base.int Base.list -> max_units:Base.int -> min_unit_bytes:Base.int -> Base.string Base.list;
    (*

    gh-ocannl-1603: the same kernels as assemble as several translation units, to be compiled concurrently and linked into one library: their units -- a kernel, or an outlined kernel's parts and the kernel -- packed by size into at most max_units sources of at least about min_unit_bytes each (0: no minimum), each with its own prelude. One unit is [assemble idxs] exactly.

    *)
  4. attribute : 'a. Base.int Base.list -> Base.exn -> Stdlib.Printexc.raw_backtrace -> 'a;
    (*

    Re-raises a failed compile of assemble idxs as compile_batch would: attributed to a routine's name when the report points at one of those kernels' declarations.

    *)
  5. key_text : Base.int -> Base.string;
    (*

    Kernel i's standalone source as a kernel code cache keys it (gh-ocannl-1525): its prelude verbatim, its definition through Kernel_code_cache.canonical_kernel -- the names it owns (symbols, scope locals, its nodes' identifiers, the emitter's minted_derivations of them) renamed by first occurrence and its segment index dropped, so that an unchanged kernel keys alike whatever names the rest of the batch made it take. The backend adds the compiler options and looks the code up by the stored symbol.

    *)
}

Renders a batch without compiling it: the kernels are rendered by one syntax instance over the whole batch, exactly as compile_batch renders them, so a kernel's text is the same whichever subset of the batch is later assembled into a translation unit.
