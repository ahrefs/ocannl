Module Ir.C_syntax

OCANNL's C-family code generator, shared by the cc, CUDA, HIP and Metal backends: renders lowered routines as C, CUDA, HIP or MSL source through a backend's C_syntax_config, and reports per-compile censuses of the renderings it chose.

type tensorization =
  1. | Not_requested
    (*

    Codegen emitted no Tile_mma statement at all: nothing about this routine claims tensor cores, and a timing of it is not a tensorized timing.

    *)
  2. | Tensorized
    (*

    At least one Tile_mma statement rendered to a real tensor-core or SIMD-register-tile emission (Mma_intrinsics, Mma_intrinsics_ldmatrix, Mma_register_tiled). The C backends' register-tiled rendering counts: it is the SIMD-tile emission those backends have, and the point of the label is fallback-vs-not, not which ISA.

    *)
  3. | Scalar_fallback
    (*

    Tile_mma statements were emitted and every one of them declined to the lane-0 scalar fallback. A timing labeled tensorized in this state measured scalar code.

    *)

Whether a routine's Tile_mma statements tensorized: none emitted, any honoured, or all fell back.

type peel_site =
  1. | Peel_localized of peel_verdict
    (*

    The site localized, deciding this.

    *)
  2. | Peel_ceded of peel_verdict
    (*

    The width decision reached a base the serial rendering would have localized, deciding this — and the site rendered a form that holds the accumulator at that same residency somewhere other than a minted scope: the warp-shuffle tree or the SIMD accumulator grid (gh-ocannl-754). Not Peel_localized, since no scope was minted; not a skip, since the width question was asked and answered wide. A test can therefore pin that the shuffle or the grid took its width from the one shared decision rather than from a recognizer of its own.

    *)
  3. | Peel_refused of Low_level.peel_refusal
    (*

    Low_level.peel_accum_nest refused, with why.

    *)
  4. | Peel_not_attempted of peel_skip
    (*

    The peel reached a base, and localization was not attempted, for this reason. Every rendering of the level then keeps the accumulator at storage width (gh-ocannl-754).

    *)

type grid_serial_reason =
  1. | Grid_opaque_body
    (*

    An opaque statement or a barrier sits under the loop body.

    *)
  2. | Grid_scope_local_escapes
    (*

    A scope local is set under the loop but declared outside it, so its function-scope storage would race across chunks.

    *)
  3. | Grid_local_accessed_outside of Base.string
    (*

    This local is written grid-variantly (it fails the shared rule) and is also accessed outside the loop body (it fails the privatization rule).

    *)
  4. | Grid_local_not_covering of Base.string
    (*

    This local fails the shared rule, and its first access per iteration is not a standalone covering write (it fails the privatization rule).

    *)
  5. | Grid_private_over_cap of {
    1. private_bytes : Base.int;
    2. cap : Base.int;
    }
    (*

    Every local the loop needs privatized could be, but their combined per-chunk footprint private_bytes exceeds cap, the resolved cc_grid_private_bytes_cap (per_chunk_private_bytes_cap).

    *)
  6. | Grid_below_min_updates of {
    1. updates : Base.int;
    2. floor : Base.int;
    }
    (*

    The launch's estimated scalar updates (grid_update_count, saturating at floor) fall below floor, the resolved cc_grid_min_updates.

    *)
  7. | Grid_offset_range of {
    1. from_ : Base.int;
    2. to_ : Base.int;
    }
    (*

    The loop does not start at 0, which the chunked rendering assumes.

    *)

Why an outermost Grid loop rendered serially on a pool-backed backend.

type async_copy_syntax = {
  1. ac_copy : dst:PPrint.document -> src:PPrint.document -> bytes:Base.int -> PPrint.document;
    (*

    One element-sized asynchronous global→workgroup-shared copy statement; dst and src are element addresses (&ident[offset]) and bytes the element size — 4 or 8 today. The hardware also copies 16, but a 16-byte copy requires a 16-byte-aligned destination, and plain workgroup-shared declarations align to the element type only (4 for uint4x32_t) — so 16 stays out of the per-element eligibility until a rendering guarantees the alignment (Codex P2 on PR #317). The copy is byte-for-byte: eligibility (same storage precision on both sides, no value transformation) is the caller's check.

    *)
  2. ac_wait_all : Base.string;
    (*

    Statement completing every asynchronous copy issued so far by the calling thread, committed or not (CUDA cp.async.wait_all). Cross-thread visibility still needs the workgroup barrier the caller emits right after.

    *)
}

Asynchronous global-to-workgroup-shared copies for staging software-pipelined tiles.

Scope collapse assumes that where Low_level.typed_at holds, the rendered text already has the type a local of its precision is declared with (typ_of_prec); under with_probes every such node of every kernel, leaves included, fails the backend's compile unless it does.
