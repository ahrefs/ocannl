Module Assignments.Fragment

A code fragment generated from a tensor, identified by its owner node and side (gh-ocannl-1724): (t.value, Fwd) is t's forward code; (t.grad, Bprop) is t's backprop code, the code propagating from t.grad into its children's gradients.

type t = Tnode.t * side
include Ppx_compare_lib.Comparable.S with type t := t
val compare : t Base__Ppx_compare_lib.compare
val sexp_of_t : t -> Sexplib0.Sexp.t
type comparator_witness
val comparator : (t, comparator_witness) Base.Comparator.t
val describe : t -> Base.string

E.g. "the backprop code propagating from grad_t", for refusal messages.
